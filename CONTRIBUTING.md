# Contributing

Issues and pull requests concerning correctness, shape compatibility, performance, documentation, and reproducibility are welcome.

1. Open an issue describing the use case or bug.
2. Reproduce with a minimal script and include PyTorch/Python versions.
3. Run `python -m pytest -q` before opening a pull request.
4. Avoid unrelated changes to the update equations; discuss algorithmic changes separately.
5. Do not upload private datasets, credential files, or model checkpoints without redistribution rights.

The original TCPELIA equations in `tcpelia/attention.py` are preserved from the supplied implementation.
